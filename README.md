# Iris Flower Classification

## Objective
Classify Iris flowers into Setosa, Versicolor, and Virginica using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Algorithm
Decision Tree Classifier

## Accuracy
96% - 100%

## How to Run

pip install -r requirements.txt

python iris_classification.py
